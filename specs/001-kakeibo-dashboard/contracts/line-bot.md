# Contract: LINE Bot（kakeibo-webhook）

**Feature**: [spec.md](../spec.md) | **Data Model**: [data-model.md](../data-model.md)

Lambda `kakeibo-webhook` の関数 URL を、LINE Developers の Messaging API チャネルの **Webhook URL** に設定する。

## 受信

- LINE Platform から `POST`。ヘッダー `x-line-signature` を `LINE_CHANNEL_SECRET` で検証する（FR-052）。検証失敗時は `401` を返し、何も返信しない。
- `events[]` のうち、`type: "message"` かつ `message.type: "text"` のイベントのみ処理する。それ以外（友だち追加・スタンプ等）は何もしない。
- LINE Developers の「検証」ボタン（`events` が空）には `200` を返す。
- 処理結果にかかわらず、署名が正しければ `200` を返す（LINE の再送を防ぐ）。

## コマンドと応答

| 受信テキスト（前後の空白は無視） | 応答 |
|---|---|
| `今月` / `今月の支出` | 当月の月次サマリーカード |
| `先月` | 前月の月次サマリーカード |
| `ダッシュボード` | ダッシュボードを開くボタン付きメッセージ（`LIFF_URL`） |
| 上記以外 | 使い方メッセージ（FR-012） |

リッチメニュー（LINE Official Account Manager で作成）のボタンは、上記のテキストを送信するアクション、または `LIFF_URL` を開くアクションにする。

| ボタン | アクション |
|---|---|
| 今月の支出 | テキスト `今月の支出` を送信 |
| 先月 | テキスト `先月` を送信 |
| ダッシュボード | URI アクションで `LIFF_URL` を開く |

## 月次サマリーカード（Flex Message）

`services/flexMessage.js` が Monthly Summary から生成する。

```text
┌───────────────────────────┐
│ 2026年10月の家計簿          │
│ 入金   ¥300,000            │
│ 支出   ¥45,000             │
│ ───────────────           │
│ 支出の多いカテゴリ             │
│ 1. 住居  ¥30,000  ⚠ 100%   │
│ 2. 食費  ¥12,000           │
│ 3. その他 ¥3,000            │
│ ───────────────           │
│ ⚠ 交通が予算を ¥2,000 超過   │   ← 超過がある場合のみ（FR-032）
│ [ ダッシュボードを開く ]       │   ← LIFF_URL
└───────────────────────────┘
```

- カテゴリは上位 3 つまで。0 件の場合は本文を「今月の入出金はまだありません」にする。
- `altText`（通知やトーク一覧に出る文言）: `2026年10月 支出 ¥45,000`
- Flex Message の作成が間に合わない場合は、同じ内容のテキストメッセージで代替してよい（research R-008）。

## エラー時の応答

| 状況 | 返信テキスト |
|---|---|
| sunabar がタイムアウト | 銀行とつながりませんでした。少し時間をおいて試してください |
| sunabar が認証エラー等 | 銀行との接続設定を確認してください |
| その他の例外 | エラーが発生しました。もう一度試してください |

- エラーの詳細（ステータスコード・レスポンス本文）は CloudWatch ログにだけ出す。**トークンや口座番号の全桁はログにも出さない**。
